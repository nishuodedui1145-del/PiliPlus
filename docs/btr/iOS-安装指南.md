# iOS 安装指南（PiliPlus BTR）

> ⚠️ **当前状态：可编译、可侧载，但未在真机上验证过。**（开发侧没有 iPhone 设备）
> iOS 包由 GitHub Actions 自动构建（`ios.yml`），产物为**未签名 `.ipa`**，需要用你自己的 Apple ID 重签后安装。
> 默认只提供 **arm64**（iPhone 8 及以后基本都满足）。

---

## 一、先搞清楚三条路

| 方式 | 适合谁 | 有效期 | 需要电脑 |
|---|---|---|---|
| **A. Sideloadly**（推荐先试） | 手边有 Windows/Mac | **7 天**（到期要重签） | 需要 |
| **B. SideStore / AltStore** | 想让它自己续签、不想老连电脑 | 7 天一轮，**同 Wi-Fi 自动续签** | 首次需要 |
| **C. TrollStore** | 系统在 iOS 14 ~ 16.x / 17.0 | **永久，不用续签** ✓ | 不需要 |

免费 Apple ID 的硬限制：**签名 7 天有效**、**最多同时 3 个侧载 App**（想装更多可以用 LiveContainer 把 App 装在容器里）。

---

## 二、方式 A：Sideloadly（Windows）

1. 装**非商店版** iTunes（官网「Windows 版 iTunes」直链，**不要**装 Microsoft Store 那个版本，否则 Sideloadly 连不上设备）；
2. 装 Sideloadly（官网 sideloadly.io）；
3. 手机用数据线连电脑，手机弹「信任此电脑」→ 同意；
4. 打开 Sideloadly：左上角选设备 → `IPA` 栏拖入 `PiliPlus-BTR_ios_<版本>.ipa` → 填自己的 **Apple ID** → Start；
5. 手机会自动开始安装（可能要输入 Apple ID 密码 / 双重验证码）；
6. 装完第一次打开会提示「**不受信任的开发者**」→ 手机 `设置 → 通用 → VPN 与设备管理 → 开发者 App` → 点自己的 Apple ID → **信任**；
7. iOS 16 及以上：`设置 → 隐私与安全性 → 开发者模式` 打开并重启一次（**必须**，否则 App 直接闪退）。

**7 天后**：App 会打不开（不是坏，是签名过期）→ 重新走一遍 4~5 步即可，**App 内的登录和数据不会丢**。

---

## 三、方式 B：SideStore（推荐长期用）

一次折腾，之后在手机上自动续签：

1. 电脑上装 **iloader**（SideStore 官方工具，Windows 可用）；
2. 手机连上后，用 iloader 把 **SideStore**（以及可选 **LiveContainer**）装进手机，并导出**配对文件**（pairing file）；
3. 手机上装 **LocalDevVPN**（SideStore 用来在本机做续签通信，需常开）；
4. 打开 SideStore → 添加**源（Source）**，把 PiliPlus BTR 的源地址加进去（若有）→ 一键安装本 App；
5. 之后 SideStore 会在**同一个 Wi-Fi** 下自动帮你续签（前提：LocalDevVPN 开着）。

> 我们的 SideStore 源是否提供取决于发布形态；如未提供，用方式 A 拖 ipa 安装同样可行。

---

## 四、方式 C：TrollStore

系统在 **iOS 14 ~ 16.x / 17.0** 的设备上，用 TrollStore 装 ipa 后**永久有效、不需要续签**，也不需要电脑。
装法看 TrollStore 官方说明（不同系统版本入口不一样）。**iOS 17.1 及以上不支持。**

---

## 五、装完之后

1. 打开 App → `我的` → 右上角齿轮 → `音视频设置` → 找到 BTR 那一组；
2. 建议值：
   - **并发上限 = 6**（iPhone 上更省电、发热更低）
   - **缓冲大小 = 32**
   - **缓冲时长 = 60**
   - 改完**退出视频重新进入**才生效；
3. 播放任意视频时，BTR 生效会走本地代理；**日志在哪看**：`音视频设置 → BTR 日志` → 页面里可以直接「复制全部」发给我们。

---

## 六、已知限制（务必先看）

- **未在真机验证**：当前 `ios/` 只保证"能编译、能侧载、代码确实进了包"，实际播放行为需要你回报；
- **后台行为**：iOS 会挂起后台 App，App 已声明 `UIBackgroundModes=audio`（后台音频），所以**后台听声音时**代理一般还能继续；但如果被系统回收，表现可能是"后台一断一续"，**前台观看不受影响**；
- **耗电发热**：多连接并发比官方播放器更耗电，建议并发 ≤ 6；
- **无法用 adb 抓日志**（iOS 没有 logcat）→ 只能用 App 内「BTR 日志」页复制；
- **4K 源**仍受海外到 B 站 CDN 的单连接限速物理天花板影响，靠缓冲抹平，不能凭空变快。

## 七、反馈方式

在 `音视频设置 → BTR 日志` 里「复制全部」，连同**机型 / iOS 版本 / 视频链接 / 现象（卡住？音动画不动？）** 一起发出来即可。
